# Личный финучёт: доходы и расходы, категории и бюджеты, отчёты и экспорт 
## 2026 сен-дек, МТУСИ 3курс 1сем

Учебный проект по курсу: "Full-stack разработка". 

## Стек
- Frontend: React + TypeScript
- Backend: Python + FastAPI
- БД: PostgreSQL + SQLAlchemy
- UI-библиотека: ...

## Функциональность
- регистрация и вход пользователей
- добавление доходов и расходов
- список операций с фильтрами
- сводка: доходы / расходы / баланс за месяц
- отчёты по категориям

## Структура проекта

- `frontend/` — React + TypeScript
- `backend/` — FastAPI + PostgreSQL
