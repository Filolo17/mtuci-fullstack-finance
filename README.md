# Личный финучёт (МТУСИ, Fullstack)

Учебный проект по курсу Fullstack. Приложение для учёта личных доходов и расходов.

## Стек

- Backend: Python + FastAPI
- БД: PostgreSQL + SQLAlchemy
- Frontend: React + TypeScript
- UI-библиотека: (определим позже)

## Функциональность

- Регистрация и вход пользователей
- Добавление доходов и расходов
- Список операций с фильтрами
- Сводка: доходы / расходы / баланс за месяц
- Отчёты по категориям

## Структура проекта

- `frontend/` — клиентская часть (React + TypeScript)
- `backend/` — серверная часть (FastAPI + PostgreSQL)
